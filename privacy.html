개인정보처리방침

시행일: 2026-10-25

스몰토크박스(이하 "채널")는 채널 운영을 위해 사용하는 내부 업로드 도구(이하 "도구")와 관련하여 다음과 같이 개인정보를 처리합니다.

1. YouTube API 서비스 사용

도구는 YouTube API 서비스를 사용합니다. 도구를 사용하는 것은 채널 운영자 본인뿐이며, 도구를 통해 YouTube API에 접근하는 모든 행위에는 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

2. 처리하는 정보

  • 운영자 계정의 인증 토큰(OAuth): 운영자 본인의 유튜브 채널에 영상을 올리고 채널 영상의 조회 통계를 확인하기 위해서만 사용합니다.
  • 운영자 채널의 영상 정보와 공개 통계(제목, 설명, 조회수 등): 어떤 주제가 반응이 좋았는지 분석해 다음 주제 선정에 참고합니다.
  • 도구는 시청자나 다른 유튜브 사용자의 개인정보를 수집·저장·분석하지 않습니다. 댓글 작성자 정보, 구독자 개인정보, 다른 채널의 데이터에도 접근하지 않습니다.

3. 저장과 보관

  • 인증 토큰은 암호화된 비밀 저장소(GitHub Actions Secrets)에만 보관하며, 코드나 공개 저장소에 기록하지 않습니다.
  • 영상 통계는 운영자만 볼 수 있는 비공개 저장소에 보관하며, 30일이 지나면 요약 통계만 남기고 삭제합니다.
  • YouTube API로 받은 데이터를 제3자에게 판매·공유하거나 광고 목적으로 사용하지 않습니다.

4. 쿠키

이 웹사이트와 도구는 쿠키나 기기 식별자를 사용하지 않으며, 방문자의 정보를 수집하지 않습니다.

5. 접근 권한 철회

도구에 부여한 유튜브 계정 접근 권한은 언제든지 Google 계정 보안 설정의 "타사 액세스" 페이지에서 철회할 수 있습니다. 권한이 철회되면 도구는 더 이상 계정에 접근할 수 없으며, 보관 중인 인증 토큰은 7일 이내에 삭제합니다.

Privacy Policy (English)

Effective date: 2026-10-25

This policy explains how Small Talk Box ("the Channel") handles information in connection with the private internal upload tool ("the Tool") used to operate the Channel.

1. Use of YouTube API Services

The Tool uses YouTube API Services. The Tool is used only by the Channel operator. By using the Tool, the operator is bound by the YouTube Terms of Service, and the Google Privacy Policy applies.

2. Information we access

  • OAuth tokens for the operator's own Google account, used only to upload videos to the operator's own YouTube channel and to read statistics for that channel's videos.
  • Video metadata and public statistics of the operator's channel (titles, descriptions, view counts), used to learn which topics perform well.
  • The Tool does not collect, store, or analyze personal information of viewers or any other YouTube users, and does not access other channels' data.

3. Storage and retention

  • OAuth tokens are stored only in an encrypted secret store (GitHub Actions Secrets) and are never written to code or public repositories.
  • Video statistics are kept in a private repository accessible only to the operator; detailed data older than 30 days is deleted, keeping only aggregated summaries.
  • Data obtained through YouTube API Services is never sold, shared with third parties, or used for advertising.

4. Cookies

This website and the Tool do not use cookies or device identifiers and do not collect visitor information.

5. Revoking access

Access granted to the Tool can be revoked at any time via the Google security settings page. After revocation, the Tool can no longer access the account, and any stored tokens are deleted within 7 days.
