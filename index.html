"선배, 그거 알아요?"

엘리베이터 안 어색한 공기를 깨는 단 하나의 무기. 스몰토크박스는 직장인이 동료·상사와 가볍게 나눌 수 있는 오늘의 스몰톡 소재를 평일 아침마다 1~3편의 짧은 영상(유튜브 쇼츠·인스타그램 릴스)으로 전해 드리는 채널입니다.

이렇게 만들어요

  • 공개된 뉴스 기사와 검색 트렌드에서 직장인이 많이 이야기하는 주제를 고릅니다.
  • 기사에 나온 사실만으로 짧은 대본을 쓰고, 영상 설명란에 원문 기사 출처를 함께 표기합니다.
  • 대본 작성과 음성(나레이션)에는 AI 도구를 활용하며, 모든 영상은 운영자가 확인한 뒤 공개합니다.
  • 정치·종교 등 회사에서 갈등이 생기기 쉬운 주제와 확인되지 않은 소문은 다루지 않습니다.

업로드 도구에 대하여

스몰토크박스는 운영자 본인이 만든 영상을 운영자 본인의 유튜브 채널에만 올리기 위해 YouTube API 서비스를 사용하는 비공개 내부 도구를 운영합니다. 이 도구는 다른 사람의 계정이나 데이터에 접근하지 않습니다. 자세한 내용은 개인정보처리방침과 이용약관을 확인해 주세요.

About Small Talk Box (English)

Small Talk Box is a YouTube Shorts and Instagram Reels channel that delivers 1–3 short videos every weekday morning, giving office workers easy conversation topics ("small talk") to share with colleagues and managers.

  • Topics are selected from public news articles and search trends. Scripts contain only facts reported in those articles, and source links are included in each video description.
  • AI tools assist with script drafting and narration. Every video is reviewed by the channel operator before it is published.
  • Small Talk Box operates a private, internal tool that uses the YouTube API Services solely to upload the operator's own videos to the operator's own YouTube channel. It does not access other users' accounts or data.
